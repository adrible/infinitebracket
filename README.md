# Brocket

Base MVP com interface mobile-first inspirada em apps de torneio.

## Já inclui

- Visual mobile-first
- Versão adaptada para PC
- Tela inicial estilo app
- Cards de criação rápida
- Playoffs funcional
- Participantes com força
- Times sugeridos
- Chance de zebra
- Simulação realista
- Goleadas possíveis
- Jogos malucos raros
- Prorrogação
- Pênaltis

## Como testar

Abra `index.html` no navegador.
