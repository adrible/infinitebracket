# Torneio Arena — Base MVP

Base inicial do site/app de torneios.

## O que já tem

- Layout responsivo para mobile e PC
- CSS global com variáveis
- Navegação entre telas
- Tela inicial
- Criar torneio
- Participantes
- Presets planejados
- Playoffs funcional
- Times com força
- Chance de zebra
- Simulação de placares
- Goleadas possíveis
- Jogos malucos raros
- Prorrogação
- Pênaltis

## Como testar

Abra o arquivo `index.html` no navegador.
