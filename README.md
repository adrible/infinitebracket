# Brocket 0.7.3

Correção em cima da 0.7.2.

## Ajustes principais

- Corrigida a tela “Torneio atual” quando não existe torneio ativo.
- A prévia do sorteio fica apenas na tela de criação.
- A hotbar recebeu mais área reservada para não cobrir informações importantes.
- A montagem rápida ficou mais limpa.
- A escolha manual avançada agora fica escondida atrás do botão “Personalizar”.
- Corrigido o botão “Simular rodada” para simular apenas a rodada/fase atual.
- Mantidos os três modelos principais:
  - Mata-mata direto
  - Grupos + mata-mata
  - Liga / pontos corridos

## Como subir

Suba somente estes arquivos na raiz do repositório:

- index.html
- style.css
- script.js
- README.md

Não suba a pasta inteira.
