# Brocket — V3

Versão com Campeonatos, Edições, Estatísticas e Bracket visual.

## Novidades

- Tela Campeonatos
- Campeonatos como pastas de edições
- Estatísticas básicas:
  - maiores campeões
  - maiores vices
  - mais finais
  - mais participações
- Hall da Fama
- Bracket com visual de chave
- Fundo esportivo/gramado
- Scroll horizontal no mobile
- Linhas conectando confrontos
- 🏆 no nome do campeão quando vence a final
- Salvamento no localStorage

## Como testar

Abra `index.html` no navegador.
